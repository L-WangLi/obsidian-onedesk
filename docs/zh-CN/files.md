# 文件

在 OneDesk 里浏览、预览和编辑整个 vault，不用切到文件列表。

![Files](../screenshots/03-files.webp)

- **左栏**：顶层文件夹，按最近活动排序，显示笔记数量和最近修改时间；最上面固定一个「最近修改」。很久没动过的文件夹会收在下方。
- **中栏**：所选文件夹里的笔记和子文件夹，最新的在前；可以逐层进入，面包屑返回上一层。
- **右栏**：所选笔记的渲染预览；切换到编辑后直接修改，内容写回原文件。如果这篇笔记在你打开后被别处改过（比如另一台设备同步过来），不会覆盖对方的修改。
- **搜索**：顶部输入框按**文件名**搜索全部笔记，右侧显示笔记总数。
- **+ Note（速记）**：在中栏当前所在的文件夹里新建一篇以日期命名的空白笔记；在「最近修改」或搜索结果里点时，建在收件箱。
