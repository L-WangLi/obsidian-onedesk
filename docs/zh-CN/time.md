# 时间

打卡记录时间去了哪里，并和你的作息计划对比。

![Time](../screenshots/08-time.webp)

## 打卡（首页）

首页有一排按钮：**Wake**、**Research**、**Work**、**Social**、**Learning**、**End**。

- **活动按钮是开关**：按一下开始；按另一个会直接切换；再按亮着的那个就暂停。切换只需一次点击。
- **End** 结束今天；**↩ Undo** 撤销最近一次误按。
- 记录保存在 `Console/Clock.md`，最新的一天在最上面，每按一次记一行，如 `- 08:30 in research`、`- 11:50 break`。它就是普通笔记，可以直接手动修改。日记通过 `![[Clock#日期]]` 嵌入当天的记录，不会复制数据。
- **跨过午夜的时段在 24:00 拆开**，后半段算到第二天。如果某个活动开始后再没有任何记录，会当作忘了点 End，不计入时长。

## 时间页

**指标**（最近 14 天）：

| 指标 | 含义 |
| --- | --- |
| **Golden hours used** | 作息表里的专注时段，实际有多少比例在做 Research 或 Work |
| **Avg / day** | 有记录的日子里，平均每天记录的时长 |
| **Avg wake** | 平均起床时间 |
| **Wake spread** | 起床时间的波动（标准差） |
| **Wake → start** | 起床到开始第一项活动，平均隔了多久 |
| **Switches / day** | 平均每天切换活动的次数 |
| **Social jetlag** | 周末和工作日平均起床时间的差 |

每项指标下面有一条小折线，显示逐日变化。

- **Today**：今天各活动的环形图，以及计划和实际并排的时间条；
- **This week**：本周日历视图，按真实起止时间画出每个时段；
- **Where the time went**：今天、本周、本月各活动的时长和占比；
- **Daily log**：最近 14 天，每天一行，显示时段分布、起床时间、跨度、工作时长和休息时长；点某一天可以打开当天的打卡记录修改。

## 作息计划

`Intake/Days/Rhythm.md` 里写一张表，第一列是时段：

```markdown
| 时段 | 活动 | 说明 |
| --- | --- | --- |
| **08:30 - 11:30** | **深潜：高强度科研** | 最专注的时段 |
| **12:00 - 13:00** | 午餐 | |
| **16:00 - 17:30** | Deep work | |
```

- 活动名里含「高强度」「深潜」「写作」或 *deep work*、*focus*、*writing* 的时段算**专注时段**，用于计算 Golden hours；
- 含「午休」「睡」「放松」「运动」「午餐」或 *lunch*、*nap*、*sleep*、*rest*、*exercise* 的算休息时段。

## 首页热力图

首页顶部的热力图显示今年每天的投入程度：完成一个任务计 1 分，每记录 1 小时计 0.5 分，按分数分成 4 档颜色。点击某一格可以手动调整档位。
