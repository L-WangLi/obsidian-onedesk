# 阅读

读书笔记的统计和最近的想法。

![Reading](../screenshots/05-reading.webp)

## 读哪些笔记

`Shelf/` 里的每一篇笔记算一本书（文件名含 dashboard 或 readme 的除外）。格式与常见的读书笔记导出插件一致，比如微信读书导出：

```markdown
---
progress: 62
readingTime: 5小时20分钟
readingDate: 2026-08-15
---
> - 分类： 个人成长-学习方法

> 📌 划线的句子
- 💭 你的想法
- ⏱ 2026-09-12 21:35:40
```

- `📌` 是划线，`💭` 是想法，`⏱` 是时间；
- `progress` 达到 100 算读完，`readingTime` 用于统计时长。

## 页面内容

| 指标 | 含义 |
| --- | --- |
| **Books** | 书的数量 |
| **Hours** | 阅读总时长 |
| **Thoughts** | 写下的想法（💭）数量 |
| **Highlights** | 划线（📌）数量 |
| **Finished** | 读完的书，及占比 |
| **Ratio** | 平均几条划线对应一条想法；越小，说明读得越主动 |

下方 **Recent** 列出最近写过想法的 5 本或 10 本书，每条显示原文、你的想法和时间。**Open library** 打开 `Shelf/` 文件夹。
